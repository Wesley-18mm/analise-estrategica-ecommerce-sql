
# Análise Estratégica de E-commerce com SQL

## Sobre o projeto

Projeto de análise de dados de e-commerce desenvolvido com PostgreSQL, utilizando consultas SQL para investigar informações relacionadas a clientes, produtos e vendas.

O projeto reúne 10 exercícios práticos que simulam problemas de negócio e demonstram a aplicação de SQL na extração, organização e análise de dados.

## Objetivo

Desenvolver habilidades em SQL e análise de dados, transformando dados operacionais em informações relevantes para apoiar decisões de negócio.

## Tecnologias utilizadas

- PostgreSQL
- SQL
- pgAdmin 4

## Competências aplicadas

- Consultas com SELECT e WHERE
- Ordenação e limitação de resultados
- Funções de agregação
- GROUP BY e HAVING
- Relacionamento entre tabelas com JOIN
- Tratamento de dados com CASE WHEN
- Análise de clientes e produtos
- Indicadores de desempenho comercial

## Estrutura do projeto

Os exercícios estão organizados individualmente na pasta `exercicios/`, com consultas SQL e objetivos específicos de análise.

## Aplicação de negócio

As consultas exploram dados de clientes, compras e produtos para gerar informações que podem apoiar análises comerciais e decisões estratégicas.
